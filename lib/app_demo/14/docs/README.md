# 聚会游戏盒 · Demo 14

## 当前阶段：批次 A · 可交互抛硬币

已实现：
- 两页、共十项游戏菜单；Coin Toss 与 Roll the Dice 可玩，其余八项明确未开放。
- 全部十项游戏使用 `assets/images/14/` 对应PNG，Build Teams 对应 `random-team.png`；所有左侧图标统一56×56逻辑像素占位，图片等比完整显示，不受原图分辨率影响；加载失败回退原有图标。
- 首页菜单为底部对齐的紧凑色带组，普通字号每项至少104px，不再均分剩余屏高；游戏名使用 NeumaticGothic-Black 24px，副标题 14px/600字重；未开放条目以「未开放」文字标签说明，不使用锁图标；长标题或大字体按内容增高并支持滚动。
- 菜单满宽、行间零间距，交错使用平直与14px斜切交界；文字图标保持水平，斜切交接区用相邻色填满。斜面主体内才响应当前项点击，交接填色不转发相邻项。
- 最后一项底边平直，背景延伸到底部安全区，文字避让 Home 指示条；底部分页栏已隐藏；首页不再提供设置入口，已保存的设置仍然生效。
- 首页左上为48px返回案例列表图标按钮；无宿主返回动作时禁用。米黄色“Pick a / Game”大标题占据菜单上方剩余空间，短屏使用紧凑单行，横屏避让侧边安全区。
- 分页提示箭头已移除，页面切换依赖拖动、分页动效和无障碍滚动语义。标题区的空白用来放页码：大标题是两行窄体字，在“又宽又矮”的标题区里受高度限制，右侧常有近一半空白，所以在右下角放 “1 / 2” 加两颗圆点，数字和圆点的底边与 “Game” 的基线对齐。
- 页码直接绑定分页进度：当前页的圆点随拖动拉长成胶囊，数字过半时切换，松手吸附和取消拖动都同步，不使用独立动画；减少动态效果时只在页面切换后跳变。它只是提示，不拦截触摸（翻页仍靠拖动，包括从标题区起手），也不进入读屏（菜单已经播报 “第 N 页，共 2 页”）。
- 页码按标题实际排版量出位置：标题放大到原始字号、“Game” 右边放不下时，页码改放右上角、与返回键同一行；紧凑单行布局（小屏）不显示。任何非紧凑尺寸都不会与标题或返回键重叠。
- 首次进入与页面返回后，五行从底部错峰上滑、轻微过冲后落稳；标准总时长1480ms、行间错峰120ms，快速900ms，减少动态120ms淡入；返回保留当前页。
- 左右滑动时整条背景色块、图片、文字和右侧图标一起逐行错峰移动；第二页将同一柔和彩色色板循环移位，让移动色界清晰可见，斜切补色取所属页下一行颜色，不添加黑缝。标准850ms、快速480ms的分页动效参数同时用于键盘翻页和松手吸附，拖动仍跟手，高速甩动限制吸附初速度。
- 标题舞台分布28颗柔和静态星点，单颗流星从右上向左下划过，每次约1秒、间隔2秒后再次出现；背景独立重绘，不遮挡菜单或拦截手势。系统/应用减少动态、后台、TickerMode关闭或路由覆盖时停止并取消等待，恢复后重新等待，不追赶补播。
- 支持标题区起手、取消拖动、键盘与无障碍分页；系统减少动态效果下无回弹和级联位移。
- 设置变化和普通重建不重播首页；游戏入口保持防重入。
- Coin Toss 页面只有顶部栏、硬币舞台和底部按钮：左上圆形半透明关闭按钮，标题 “抛硬币” 相对整屏居中，右侧不放任何按钮。没有设置、外观切换或历史记录，硬币固定为金色。
- 点击硬币和点击底部按钮走同一个抛掷命令，一轮只产生一次结果；抛掷和揭晓阶段硬币与按钮同时锁定，抛掷中点硬币无响应也不排队。
- 硬币点击热区以硬币轮廓为准并外扩 8pt，光晕和圆环不响应点击；按下时硬币缩到约 96%，按钮缩到约 97%。读屏标签 “点击硬币开始抛掷”。
- 硬币直径约为屏宽 58%，静止时中心在屏高 43% 处；抛到最高点时中心升到约屏高 12%–20%，上沿接近屏幕顶部并盖住标题栏。正面是皇冠加 “正面”，反面是五角星加 “反面”。
- 每个有效回合只抽取一次结果；状态依次为 idle → running → revealing → result，揭晓前不公开结果文案。下一轮从上一轮落定朝向继续，每轮至少多转 6 个半圈。
- 结果区在硬币下方：首次进入时为空，按钮显示 “抛一次”；抛掷中显示灰色 “抛掷中…”，按钮变暗并同样显示 “抛掷中…”；揭晓后显示金色小标签 “硬币说” 和白色大字 “正面” / “反面”，按钮变为 “再抛一次”。
- 文字切换错开约 100ms：新一轮开始时旧结果先淡出、“抛掷中…” 稍后淡入；揭晓时 “抛掷中…” 先淡出、结果稍后淡入并轻微上移，避免新旧文字叠在一起。
- 揭晓时硬币外侧扩散三圈细金线圆环，圆环有独立时间轴，按钮解锁后仍继续扩散；下一轮开始时残留的圆环随文字切换一起淡出。减少动态效果下不播放圆环。
- 标准 2550ms（约 2250ms 揭晓）、快速 1150ms、减少动态效果 200ms；系统减少动态效果优先，此时硬币不翻转，只淡入到结果朝向。
- 切后台直接结算已确定的结果，不重抽、不补震动；页面返回当刻取消动画和后续反馈，不等待退出转场结束。
- 揭晓时触发一次轻触反馈，没有开关；反馈服务不可用时仍能正常完成回合。结果揭晓时才向读屏播报 “本轮结果：正面” 或 “本轮结果：反面”。
- 动画速度、减少动态效果、震动写入本地设置，目前没有界面入口修改，读取失败时回退默认。
- Roll the Dice（掷骰子）页面：选择一枚或两枚骰子，点击底部按钮或任一骰子掷出，落定后显示大号合计；两枚时下方给出分项，如 “5 + 2”，一枚只显示点数。顶部只有关闭按钮和居中的标题，没有头像、更多或其他设置。
- 骰子是真正的 3D 带倒角立方体：六个面内缩、十二条棱和八个角用小面片连接，按法线光照着色，点数画在各个面上随面透视；边长约为屏宽 26%，相对两面点数之和为 7。待机时一枚居中（点数 1），两枚并排居中（点数 1 和 2，间距为边长的 55%），中心约在屏高 49%。
- 翻滚：点击后立刻起动（先有约 5% 的蓄力收缩，不留静止期），沿弧线在屏幕里抛起、位移并大幅翻转，落地有一次衰减的小弹跳，旋转减速到精确停在落定姿态；两枚骰子路径、翻转轴各自独立，可以互相擦过。标准约 2.25 秒、快速约 1.1 秒，落定后结果再淡入约 0.25 秒，合计约 2.5 秒。
- 点数在点击瞬间由规则确定，动画落点必须与之一致：落定姿态是“点数面朝向观察者”再叠加很小的倾斜和面内旋转，翻滚中途露出的点数只是视觉效果。合计只由最终点数计算。
- 随机落点只在舞台区内：中心在屏高 30%–52% 之间，距左右边缘至少 16pt，骰子下沿不越过结果区（63%）、上沿不碰数量切换；两枚骰子中心距不小于边长的 1.3 倍，不重叠；第一枚总是落在左边，分项 “第一枚 + 第二枚” 从左到右读与屏幕上的点数顺序一致。
- 数量切换是 “一枚骰子 / 两枚骰子” 分段控件，只在待机和结果态显示，翻滚中淡出且不可点；切换立即清除旧结果、骰子换回待机姿态、按钮回到 “掷一次”，选择当前已选项不做任何事。
- 文字与控件的显隐：待机显示小标签 “全凭运气” 和标语 “手气如何？”；翻滚中结果区完全留空，状态提示放在按钮上；落定时按钮解锁与合计出现同步。旧结果淡出 150ms，待机文字晚 100ms 才开始淡入，避免新旧文字叠在一起。
- 按钮三态：待机 “掷一次”（酒红、带骰子图标和淡红光）、翻滚中 “投掷中…”（深灰、无图标、无红光、不可点）、结果 “再掷一次”。主题是深黑底加暗红光晕，抛硬币页是金色，两者靠主题色区分；背景铺满整屏，状态栏下方没有色阶。
- 翻滚中切后台或系统开启减少动态效果：直接落定已经确定的结果，不重抽、不补震动；减少动态效果下不翻滚也不抛起，骰子在落定位置约 200ms 淡入。落定时触发一次轻触反馈，没有开关；退出页面时立即停止动画且不再触发任何反馈。
- 读屏：结果落定后才播报 “本轮结果：合计 7，分别是 5 和 2”（一枚为 “本轮结果：3”），翻滚中不播报；被清除的旧结果不再暴露给读屏。

- 内部关闭与退出 Showcase 案例的导航边界，以及未知路由提示。

不包含声音、网络、传感器、真实物理引擎（骰子的运动是预先规划的轨迹，不模拟碰撞）、历史记录、外观切换或其余八个游戏。原始技术任务书 `FLUTTER_AI_IMPLEMENTATION_BRIEF.md` 保持不变，不自动推进批次 B。

## 代码组织

- `app_14.dart`：应用壳、设置初始化、宿主与内部导航边界、测试依赖注入。
- `models/`：菜单和不可变状态、硬币规则、回合/设置 ViewModel、随机与反馈服务、持久化仓库。
- `screens/`：双页首页、可交互硬币页、掷骰子页、集中式路由。
- `widgets/`：主题、UI 动效、菜单、按压组件、硬币时间轴/双面绘制/揭晓圆环和底部按钮；`widgets/dice/` 是骰子的运动数学（旋转、面朝向、舞台布局、运动计划）、3D 绘制、数量切换、按钮和主题。

保留项目包名，不创建独立 Flutter 子工程。`app_14.dart` 是 Widget，不包含独立 main 函数。

设置复用已有 `shared_preferences`，使用独立键 `party_box.demo14.settings` 和 schema 版本 1，不改其他 Demo 的数据。写入顺序执行；结果及回合本身不持久化。
