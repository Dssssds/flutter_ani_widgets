# 拾页 · Demo 16

## 当前阶段与交付范围

APP-16「拾页」已完成三页及全部交互：手账、素材抽屉、翻看。实现只使用本地种子数据与本地持久化，不联网、无账号。默认演示时钟固定为 **2026-10-04**，启动即进入这一天的手账「有风的下午」；翻看默认停在 **2026 年 9 月、选中 27 日**。

原始交接包（规格、任务提示词、种子、素材与参考图）完整保留在 `docs/shiye-flutter-handoff/`，本文件记录已经实现并验证的交付内容。

## 已实现行为

### 应用壳与导航

- `App16` 是独立 Widget 应用壳，已登记在 Showcase 的 `demoApps`（`APP-16(拾页)`，全屏），不创建独立 `main()`。
- 内容固定在 390×844 设计画布内：窗口更宽时水平垂直居中，画布外铺 `#EAE3E7`；更窄时使用实际宽度并允许纵向滚动。
- 浅色主题、SafeArea、系统文字缩放夹在 0.9–1.2 之间；三个页面用 `IndexedStack` 保留滚动与选择状态。
- 底部导航「手账 / 素材 / 翻看」：实心莓色胶囊在 240ms 内滑动到目标项，图标转为白色并与文字同步缩放；导航高 64（矮屏 58），延伸到屏幕底部并避让 home indicator；重复点击当前页不重建页面。
- 在素材或翻看页按系统返回会回到手账；手账页不再拦截返回。
- 全局 Toast 固定在底部导航上方，显示 4.2 秒；成功、撤销、失败提示共用同一通道。

### 手账页

- 日期头部显示大号日数、月份 / 星期、年份；点「拾页」品牌按钮回到今天。心情按钮在「好心情 / 被治愈了」间切换，太阳 / 爱心图标同步。
- 手账页按「顶栏 / 可滚动纸面区 / 常驻工具栏」排布：390×844 下纸面与底部工具栏（照片 / 贴纸 / 胶带 / 文字）无需滚动即完整可见；更矮的屏幕仍可滚动查看。
- 纸面包含点阵、纸纹、打孔、标题、正文、天气小票与两张拍立得；主拍立得和小拍立得可按住拖动，选中时出现选择描边和「完成」按钮。
- 文字工具打开底部弹窗：标题最多 10 字、正文最多 75 字，首尾空白会被去除；标题或正文为空时不能提交，关闭弹窗不写入。
- 照片工具调用系统相册；图片最长边压到 700、质量 82，解码校验后复制到应用文档目录 `photos/<uuid>.jpg`，再把持久路径写进手账。取消不产生修改；读取或写入失败显示「这张照片没有读出来，换一张试试」。
- 贴纸、胶带、便签、照片四类素材均可贴入；贴纸且未开启减少动态时播放飞入动画，动画期间对应已贴素材隐藏，结束后 Toast「已贴上，按住可以移动」。
- 拍立得和已贴素材的拖动都按未旋转尺寸夹紧到纸张内；移动超过 2px 才记录一步撤销，不会把一次拖动拆成几十步。
- 撤销最多保留 15 步；撤销后恢复为未保存状态；无历史时按钮置灰且不可点。
- 保存串行执行，连续点击只写入一次；成功后按钮显示「已保存」并 Toast「这一页，收好了」，再次修改回到「保存」；失败保留纸面内容并显示错误提示。
- 切换日期会清空撤销历史，但在内存中保留各日期的未保存草稿；重新打开同一天可继续编辑。

### 素材抽屉

- 四个分类「贴纸 / 胶带 / 便签 / 照片」带滑动高亮；每类显示封面、分类标题、说明与数量（6 / 6 / 6 / 4）。
- 素材单选，切换分类会记住该分类上次选中的素材；底部托盘显示预览、名称与「贴到手账」按钮。
- 贴入位置、角度来自 `materials.json` 的 `pasteDefaults`；上传照片使用单独的 `uploadedPhotoDefault`，与抽屉照片不共用坐标。
- 贴入后自动回到手账页；贴纸飞入的起止坐标会换算到应用内容画布的局部坐标，宽屏居中时也不会偏移。
- 开启减少动态时不创建飞入状态，素材直接出现在纸面上，其余行为不变。

### 翻看页

- 默认 2026 年 9 月、选中 27 日，显示「写下了 17 天」；月历按周一开头，正确显示前导空格、有记录缩略页与无记录圆点。
- 缩略页按优先级取：第一张已贴照片 → 基础主拍立得 → 第一张便签 → 第一张贴纸 → 条目类型；都没有时显示空白页。
- 未来日期降低不透明度且不可选；月份不能晚于演示当月的 2026-10，下月按钮置灰。切月后默认选中该月最后一个有记录日。
- 选中日期的摘要卡显示日期、缩略图、标题与正文；无记录日期显示空白模板。点击卡片进入当天手账，任意过去日期都可以打开。
- 保存某天后，月历缩略页、当月天数和摘要卡会立即使用新数据；保存的结果覆盖同日种子，不重复计数。

## 数据与持久化

- 种子：21 条手账（2026-09 共 17 条、2026-10 共 4 条），素材 6 贴纸 + 6 胶带 + 6 便签 + 4 照片，全部从 `assets/images/16/seed/` 读取。
- 存档键为 `shiye-entries-v1`，内容是按 `YYYY-MM-DD` 索引的 JSON。读取时逐条容错：整体损坏、根节点类型错误、键非法或单条解析失败都会跳过，不导致启动失败。
- 未知字段被忽略，缺失字段回退默认值；`DiaryEntry` 往返保留上传照片路径、素材列表、归一化坐标与角度。
- 上传照片落在应用文档目录而不是临时目录，重启后仍可通过保存的绝对路径显示。
- 未保存草稿只存在内存中；本案例不做云端备份。

## 动效、响应式与无障碍

- 动效时长集中在 `App16MotionSpec`：按压 180ms、导航高亮 240ms、纸面入场 420ms、贴纸飞入 680ms、Toast 4.2s + 200ms 淡出。
- 系统「减少动态」生效时：关闭纸面入场、贴纸飞入和按压缩放，导航 / Toast / 弹窗过渡时长归零，功能保持完整。
- 主要点击目标不小于 44×44；图标按钮、导航、心情、撤销、保存、素材、文字工具、月份箭头、日期格和摘要卡都有中文语义标签。
- 320×700、1.2 倍文字缩放下，三个页面都可滚动且无布局溢出；日期、月份标题等固定区域使用单行省略或缩放兜底。

## 明确不包含

账号、登录、云同步、多设备、分享、导出图片 / PDF、打印；删除素材、缩放、自由旋转、图层顺序、复制粘贴；富文本、字体或颜色选择；多语言、深色模式；真实天气、提醒、打卡统计；Web / 桌面正式交付。

## 状态流转

1. 启动：`DiaryController.initialize()` 加载种子与存档，合并后以今天（演示为 2026-10-04）为初始条目；演示模式把翻看视图初始化为 2026-09 / 27。
2. 编辑：心情、文字、上传、贴入、首次拖动都先 `snapshot()` 再写入新条目；所有条目对象不可变，列表在 `deepCopy` 时做不可变包装。
3. 贴入：读取素材默认坐标 → 生成 `PlacedItem` → 切回手账 → 若为贴纸且允许动效，生成 `FlyingRequest`；壳层播放 680ms 后调用 `finishFlying()` 清空状态并 Toast。
4. 切日期：当前条目存入内存草稿 → 依次查草稿、存档、种子、空白模板 → 清空撤销历史。
5. 保存：`saving` 锁防止并发；成功后写入 `savedEntries` 并标记已保存，失败保留条目与错误提示。
6. 翻看：条目统计与缩略页实时由 `seedEntries + savedEntries` 推导；保存后无需手动刷新。

## 与规格书的差异

- 原始交接包从 `docs/` 根目录移入 `docs/shiye-flutter-handoff/`，内容未改写；交付说明放在 `docs/README.md`，符合仓库「任务书与交付文档分开」的约定。
