## 当前阶段：M2–M6 完成

本案例已完成 APP-15 的全部里程碑：学习路径、选词填空、听音选图、课后结算、复习词卡、成就、个人目标，以及响应式、无障碍、减少动态效果与演示配置。所有业务数据来自本地状态并实时推导，不联网。

## 已实现

### M1 · 学习路径与基础设施

- `App15` 是独立 Widget 应用壳，已登记在 Showcase 的 `demoApps`；不创建独立 `main()`。
- 设计系统按产品 token 落地：奶油纸底 `#FFFEF8`、墨色 `#242522`、主黄 `#FFD83D`、薄荷 `#B9EADD`、警示红 `#F47861`；2px 描边、硬阴影、大圆角；Nunito + 中文回退字体；390×844 设计基准，宽屏内容最大 430。
- 初始演示数据：1,284 XP、4 条生命、连续 7 天（不含今天）、每日目标 10 分钟、今日已学 6 分钟；打招呼与看懂菜单已完成，点杯咖啡为当前课，后两课锁定；声音默认关闭。
- 学习路径页：资源栏、单元横幅、今日目标、350×425 设计画布缩放、节点状态（已完成 / 当前 / 未解锁）、小鸟、底部 CTA 与导航。
- 种子数据、纯规则层（streak / 解锁链 / 当前课 / 每日目标 / 复习起点 / 成就推导）与本地存档（独立命名空间、schema 2、串行写入、容错读取、跨天重置）。
- `PipController`（`ChangeNotifier` + 构造注入）集中管理状态；UI 通过 `ListenableBuilder` 订阅，无全局状态库。

### M2 · 选词填空与结算

- 两种题型共 15 题；填空支持选词、检查、正确 / 错误反馈、连击徽章、生命扣除、重试与补满生命。
- 首答正确率：`correctFirstTry / total`，答错重试不会恢复正确率；每日分钟按答对 +30 秒并封顶。
- 首次完成课程发放 XP 并逐级解锁：点杯咖啡 → 问个方向 → 单元挑战；复习模式不发 XP。
- 结算页：庆祝构图、真实正确率、本课经验、连续学习卡、CTA 与脚注；演示结算与挑战通关分别使用对应文案；使用 `pushReplacement` 防止返回题目。
- 退出答题保留 `qIndex / selection / feedback / firstTry`，回路径显示“继续这一课”和已完成题数；不同模式分开保存。

### M3 · 听音选图与音频

- 咖啡、问路、挑战都包含听音题；选项使用插图卡片，选中项在禁用后仍保持可读。
- 本地 WAV 通过 `just_audio` 播放，TTS 通过 `flutter_tts` 兜底；播放中显示“正在播放…”，失败 Toast “这次没播放出来，点一下再听。”。
- 离开答题页、切 Tab、进入词卡时停止播放；`soundOn` 只控制答对 / 结算 chime，不影响听力 WAV 与词卡发音。

### M4 · 复习

- 复习首页：0/17 总览、四个主题卡（点杯咖啡、打个招呼、看懂菜单、问个方向）与各自进度。
- 词卡：翻转、看中文、先跳过、还不熟、记住了；已掌握标签、掌握去重、轮次与完成态；全掌握主题仍可从第一张复习。
- 进入某主题后返回复习首页时保持原主题；打招呼 / 看懂菜单节点直接打开对应词卡，不进入测验。

### M5 · 成就与个人页

- 5 枚徽章全部由状态实时推导；未获得行图标灰度 + 65% 不透明度。

## 代码组织

- `app_15.dart`：应用壳、加载态、依赖注入、演示路由、Toast 通道与 Showcase 挂载点。
- `data/`：种子数据、演示初始状态、资产清单。
- `models/`：不可变 `AppState`、课程 / 题目 / 词条 / 成就 / 运行态 / 结算结果；`rules/` 纯规则；`services/` 音频、分享、时钟、偏好存储；`repositories/` 存档；`view_models/` 控制器。
- `screens/`：`RootShell`、学习路径、答题、结算、复习首页、词卡、成就、个人页。
- `widgets/`：主题与设计 token、通用按钮 / 图标 / 进度 / Toast / 设备框 / 导航、路径画布、动效参数。
- `docs/lingo-flutter-handoff/`：产品交付包原样保留，作为实现与验收依据。

所有状态对象不可变，集合在构造时做 `unmodifiable` 包装；规则层不依赖 Flutter UI，可在纯 Dart 测试中验证。
